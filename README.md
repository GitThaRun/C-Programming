# ⚙️ C Practice Projects 💻

Welcome to my C programming playground! 🧪  
This repository contains a collection of beginner-to-intermediate level C programs built for self-practice and concept clarity.

---
## 📁 Projects Included

| Project | Description |
|--------|-------------|
| 🔢 Calculator using Switch | Basic calculator using switch-case structure. |
| 📊 Marks Analyzer | Takes student marks and calculates average, grade, etc. |
| 🔁 Loop Patterns | Print star patterns using nested loops. |
